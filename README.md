# creative-living-catalog

The content catalog for the Creative Living custom screens in the Circle app and web community.

- `catalog.json` is **generated every day** by the catalog sync in the private `creative-living-app` repo. **Never edit it by hand**: the next sync overwrites it, and only the sync may publish here.
- It's served at `https://creative-living.github.io/creative-living-catalog/catalog.json`, and the screens download it from there.
- It only lists titles, links, covers and labels of content published in the community. No member data.
- The history of this repo is the audit trail of what the screens showed and when (CL-ADR-16).
